# Recette de lancement — 23 octobre 2026

## Version préparée

Cette branche reprend la PR #30 (elle-même incluant #29), encore non fusionnée lors du contrôle. Ne pas fusionner les anciennes propositions séparément.

- Suppression du client API Yalidine, des actions serveur, du formulaire d’expédition et du cron Vercel. Historique et modes de règlement conservés.
- Catalogue de 12 articles issu des deux images du propriétaire. Paliers 1–19 / 20–49 / 50 et plus ; Events minimum 50. Gilet rouge et combinaison sur devis, sans prix inventé. Aucun stock physique ni coût d’achat inventé.
- Calcul des tarifs par quantité dans le configurateur et les documents commerciaux. Les montants négociés restent modifiables. Les tarifs des documents existants ne sont pas rétroactivement remplacés.
- Création client/commande/articles/impressions/acompte dans une transaction sous les droits de l’utilisateur. Échec : rollback complet. Reprise avec le même identifiant : pas de deuxième commande ni deuxième acompte. Un fichier joint reste hors transaction ; son échec est affiché explicitement.
- Chargement des documents bloqué en cas d’erreur des lignes ou du catalogue, au lieu de présenter silencieusement une liste vide.

## Blocages production

L’accès Vercel à l’équipe `yakoubi-mohamed-s-projects` renvoie 403. Le projet Supabase accessible `Caractere.store` ne contient pas les tables ERP : ce n’est pas une preuve d’accès à la base cible. Aucune migration ni création d’article dans une base réelle n’a été exécutée.

Avant mise en service : identifier la base réellement configurée dans Vercel, contrôler son registre de migrations et sauvegarde, appliquer les migrations manquantes avec `npm run db:migrate`, déployer le même code et effectuer une recette avec un compte commercial. Ne pas utiliser `--baseline` pour simuler l’application des correctifs. Retirer les anciennes variables YALIDINE_API_ID / YALIDINE_API_TOKEN / YALIDINE_FROM_WILAYA dans Vercel ; le nouveau code ne les utilise plus.

Les prix fournis ne précisent pas HT/TTC. Aucun taux légal n’a été inventé : nouveaux produits à taux 0, taux existants préservés. Confirmer le paramétrage fiscal avant émission réelle. Le stock initial et les soldes historiques doivent être rapprochés des quantités et espèces réelles. Stock par variante, avoirs/remboursements et restauration d’une sauvegarde réelle ne sont pas certifiés par cette recette.

**Conclusion : version corrigée et testable ; mise en production non validée tant que ces contrôles ne sont pas faits.**
